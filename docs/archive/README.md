# docs/archive/

Historical material, kept for context only. **Nothing here is current.**

- `superpowers/plans/`, `superpowers/specs/` — refactor plans written before the
  consolidation waves. Their file paths describe the tree as it was at the time and do
  not match the current one (e.g. they reference `lib/services/line-service.ts`,
  `lib/offline-first/*`, and `tests/scripts/`, none of which exist today).
- `offline-first-architecture.md` — an aspirational WASM + signed-tile-manifest design
  that was never built.
- `WASM_SETUP.md` — WASM build guide for that unbuilt design; not required by the
  current JS engine.
- `mega-spec-assessment.md` — coverage against the original MEGA offline-first
  requirements; most MUST items remain unimplemented by design.

**For the current architecture, read `docs/architecture.md` instead.**
